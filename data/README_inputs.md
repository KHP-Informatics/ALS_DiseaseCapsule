# Input data requirements

Raw genotype data are not included in this repository because they are controlled-access human genetic data.

To run the full workflow, users need to provide:

## 1. GWAS summary statistics

Expected as one file per chromosome, e.g.:

```text
summary_statistics/als.sumstats.meta.chr1.txt
summary_statistics/als.sumstats.meta.chr2.txt
...
```

The template SNP-selection script assumes:

- column 2 = SNP identifier
- column 6 = minor allele frequency or comparable frequency field
- column 9 = p-value

Edit `scripts/00_select_significant_snps.sh` if your columns differ.

## 2. Genotype files

The pipeline can start from PLINK binary files and then convert/extract to VCF using your local workflow.

For gene matrix creation, the cleaned Python script expects VCF files such as:

```text
all.sig.1.vcf
all.sig.2.vcf
...
```

The VCF must contain GT fields and samples in the same order as the phenotype file.

## 3. Phenotype / labels file

A delimited file with at least the following columns:

```text
FID     Pheno
sample1 1
sample2 2
```

Phenotype coding:

- `1` = control
- `2` = ALS case

## 4. ANNOVAR annotation files

The workflow expects files such as:

```text
annotations/chr1.variant_function.uniqGene
annotations/chr2.variant_function.uniqGene
...
```

The simplified expected format is at least three columns:

```text
chrom_or_chr  snp_id_or_position  gene
```

These are generated by `scripts/01_annotate_snps_annovar.sh`, but you may provide your own equivalent SNP-to-gene mapping.
